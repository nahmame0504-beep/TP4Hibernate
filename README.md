TP Hibernate : Persistance des Données en Java avec MySQL
Bienvenue dans ce TP consacré à la configuration et à la mise en œuvre d'une application Java utilisant Hibernate et MySQL pour gérer la persistance des données.

Chaque étape du TP est détaillée pour faciliter la compréhension des concepts fondamentaux de la persistance objet-relationnelle et le déploiement d'une architecture propre et évolutive.

 Objectifs d'apprentissage
Comprendre les ORM : Maîtriser le fonctionnement de l'Object-Relational Mapping (ORM) avec Hibernate.

Configuration : Configurer Hibernate via Maven et un fichier de configuration XML (hibernate.cfg.xml).

Architecture en couches : Mettre en place une séparation claire des responsabilités (Entités, DAO, Services).

Interface Générique : Utiliser l'interface générique IDao<T> pour standardiser les opérations de persistance dans toute l'application.

Tests Unitaires : Valider les opérations CRUD (Create, Read, Update, Delete) à l'aide de JUnit.
Prérequis techniques
Pour réaliser ce lab dans les meilleures conditions, vous devez disposer de :

Java Development Kit (JDK) : Version 11 ou supérieure.

IDE Java : IntelliJ IDEA, Eclipse ou NetBeans.

Apache Maven : Pour la gestion des dépendances et la construction du projet.

Serveur de Base de Données : MySQL opérationnel (ex. via XAMPP, WampServer, Docker ou installation locale).
